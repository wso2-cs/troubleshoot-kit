Getting Started
Follow the steps below to set up and run LogAnalyzer on your machine.

1. Download the Repository
Download the LogAnalyzer repository from the following path:
(https://github.com/sayurax/LogaAnalyzer)

2. Extract the Files
Once the download is complete, unzip the downloaded archive to a location of your choice.

3. Run the Application 

Windows
Navigate to the extracted folder.

Double-click on the LogAnalyzer.exe file to launch the application.

Mac
Navigate to the extracted folder

Open the Log_Anallyzer file and type ./Log_Anallyzer and run

4. Open in Browser
After launching:

A terminal window will open automatically.

Either click the link shown in the terminal (usually http://localhost:8080)
OR

Manually open your browser and go to:
http://localhost:8080

That's it! You're now ready to use LogAnalyzer.
